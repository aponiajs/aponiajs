# Operations

Running, releasing, and handing an AponiaJS application to another operator or
an AI agent. Read this category before deploying, cutting a release, or giving an
agent write access to a repository.

## When to read what

| Page                                        | Answers                                                                       |
| ------------------------------------------- | ----------------------------------------------------------------------------- |
| [Deploying an application](./deployment.md) | Topology, state ownership, probes, shutdown, configuration, and failure modes |
| [Releasing npm packages](./releasing.md)    | Channels, the version gate, the publish flow, and the SBOM                    |
| [Working with AI agents](./ai-agents.md)    | Context order, change protocol, safety boundaries, and required evidence      |

## Start here

Read [Deploying an application](./deployment.md) before the first production
deployment. Read [Releasing npm packages](./releasing.md) before pushing to a
release branch, and [working with AI agents](./ai-agents.md) before delegating
a change to an agent.
