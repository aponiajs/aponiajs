# Tooling

The generator, the library contract, and the authoring path for a package that
ships an Aponia module. Read this category when creating an application,
generating a resource, or publishing code that other applications import.

## When to read what

| Page                                               | Answers                                                         |
| -------------------------------------------------- | --------------------------------------------------------------- |
| [Aponia CLI](./cli.md)                             | Every command, schematic, alias, option, and generated file     |
| [Authoring a library](./libraries.md)              | Creating, checking, and publishing an AponiaJS library          |
| [Authoring a plugin package](./plugin-packages.md) | Wrapping a native runtime plugin in a publishable Aponia module |

## Start here

Read [Aponia CLI](./cli.md) to create an application or generate a resource.
Read [Authoring a library](./libraries.md) before publishing a package, and
[authoring a plugin package](./plugin-packages.md) when the package mounts a
native runtime plugin.

Return to the [documentation index](../README.md).
