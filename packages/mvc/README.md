# @aponiajs/mvc

Universal multi-engine and SSR framework bridges for Next.js, Nuxt.js, Angular, Express, and Fastify in AponiaJS.

## Installation

```bash
bun add @aponiajs/mvc@beta
```

## Bridges

- **createNextHandler**: Next.js custom server bridge
- **createNuxtHandler**: Nuxt 3 Nitro renderer bridge
- **createAngularHandler**: Angular CommonEngine SSR bridge
- **toExpressHandler**: Express middleware adapter
- **toFastifyHandler**: Fastify route handler adapter
